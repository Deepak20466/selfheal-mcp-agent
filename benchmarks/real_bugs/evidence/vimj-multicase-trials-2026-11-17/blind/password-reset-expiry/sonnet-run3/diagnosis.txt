reset_password compares entry.expires_at with datetime.now(timezone.utc), which is timezone-aware. The token is stored with an aware UTC datetime, but SQLite (and a DateTime column without timezone=True) returns a naive datetime when it is read back. The comparison therefore raises "can't compare offset-naive and offset-aware datetimes". The fix treats a naive expires_at as UTC before comparing. Aware values are left as they are. Expired tokens still return 400.
