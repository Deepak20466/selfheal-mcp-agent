SQLite and DateTime columns without timezone=True give back naive datetimes. In reset_password, `entry.expires_at` (naive) is compared with `datetime.now(timezone.utc)` (aware), and Python raises TypeError. Expiry values are always written in UTC (`datetime.now(timezone.utc) + ...`). So the fix treats a naive `expires_at` as UTC before the comparison and leaves already-aware values as they are. Valid tokens are now accepted and expired tokens still return 400.
