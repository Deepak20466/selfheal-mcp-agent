SQLite (via SQLAlchemy DateTime without timezone=True) returns naive datetimes, even though the token was stored from an aware UTC datetime. reset_password compares entry.expires_at (naive) with datetime.now(timezone.utc) (aware), which raises TypeError. The fix treats a naive expires_at as UTC, using a local variable so the ORM entity isn't modified, and then compares. Expired tokens still yield 400 and valid tokens pass.
