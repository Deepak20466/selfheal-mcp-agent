reset_password compares entry.expires_at with datetime.now(timezone.utc), which is timezone-aware. Some database backends drop timezone info when they store a datetime. SQLite does this even for DateTime(timezone=True) columns, so expires_at comes back naive and the comparison raises TypeError. The tokens are always created as UTC times, so the fix is to treat a naive expires_at as UTC before comparing. Aware values are left unchanged. A valid token then passes and an expired one still returns 400.
