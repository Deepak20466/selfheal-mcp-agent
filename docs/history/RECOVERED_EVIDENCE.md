## Scope and validity limits

This is a reconstruction from retained records. Session notes are not independent instrumentation, PR state can change, and only retained or still-accessible Actions logs can be checked. Several early records describe seeded in-repository defects, one synthetic fixture, or manual code review; none is a broad sample of real-world repairs. The real-bug benchmark harness on the current branch has not been run, so its resolve rate, full-suite-green resolve rate, false-positive rate, median time/cost, and failure taxonomy have no measured values.
